====================================================
0. 이 프로그램이 뭔가요?
====================================================
내 영상을 "유튜브에 올리기 좋은 상태"로 자동으로 다듬어서, 한 번에 완성 영상으로
내보내 주는 무료 프로그램입니다. 인터넷에 안 보내고 내 PC 안에서만 처리합니다(100% 로컬).

자동으로 해주는 일:
  • 서로 다른 영상들의 화면 규격(해상도/프레임)을 똑같이 맞춰 깔끔하게 이어붙이기
  • 자막(SRT/ASS)을 영상에 직접 새겨 넣기 (한글 폰트 자동)
  • 소리 크기를 유튜브 권장 기준(-14 LUFS)으로 자동 정리
  • 유튜브가 좋아하는 형식(H.264 MP4)으로 내보내기
  • 썸네일 후보 이미지 뽑기 / 화질 4배 업스케일 / 배경 제거 (선택)
  • (선택) 내 유튜브 채널에 비공개/예약으로 바로 올리기

설계 원칙: "무료보다 신뢰성". 같은 영상을 넣으면 항상 같은 결과가 나오도록 만들었습니다.


====================================================
1. 준비물
====================================================
  • 윈도우 PC (이 도구는 윈도우용으로 만들어졌습니다)
  • 파이썬(Python) 3.11 — 없으면 https://www.python.org 에서 설치
  • ffmpeg — 영상 처리 엔진. 없으면 아래 명령으로 설치:
        winget install Gyan.FFmpeg
  • (선택) 화질 업스케일/배경제거는 그래픽카드(GPU)가 있으면 더 좋습니다.
    업스케일은 옆 프로젝트(ReMaster)의 엔진을 그대로 빌려 쓰므로 추가 설치가 없습니다.

  ※ 영상 내보내기(제일 중요한 기능)는 GPU 없이도 잘 돕니다.


====================================================
2. 처음 한 번만 — 설치하기
====================================================
1) 윈도우 탐색기에서 creator-toolset 폴더로 들어갑니다.
2) 주소창이나 빈 공간에서 PowerShell을 엽니다. (또는 시작메뉴 → "PowerShell")
3) 아래를 입력하고 엔터:

     cd "C:\Users\(내계정)\Desktop\home-desktop project\creator-toolset"
     .\scripts\setup_windows_desktop.ps1

   → 파이썬 가상환경(.venv)을 만들고 필요한 부품을 자동으로 설치합니다.
     "완료"라고 나오면 끝. (처음 한 번만 하면 됩니다.)

   만약 "스크립트 실행이 차단됨" 같은 메시지가 나오면, PowerShell에 한 번만:
     Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   를 입력(Y 엔터)하고 다시 시도하세요.


====================================================
3. 켜기 / 끄기 (서버 실행과 종료)
====================================================
[켜기]
1) creator-toolset 폴더에서 PowerShell을 열고:
     .\scripts\run_server.ps1
2) "http://127.0.0.1:8020" 라고 뜨면 성공.
3) 웹브라우저(크롬/엣지) 주소창에  http://127.0.0.1:8020  를 입력해 접속합니다.
   → 이 프로그램의 화면이 열립니다.

[끄기]
  • PowerShell 창에서 Ctrl + C 를 누르거나, 그 창을 닫으면 종료됩니다.

  ※ 이 프로그램은 "내 PC 안에서만" 도는 작은 서버입니다. 인터넷에 노출되지 않습니다.


====================================================
4. 화면 둘러보기
====================================================
화면은 위에서 아래로 ①②③④ 순서입니다.

  맨 위   : 제목 + 오른쪽에 상태표시(ffmpeg OK / 폰트 OK 가 보이면 정상)
  📖 안내 : "처음이세요? 1분 사용법" — 펼쳐보면 짧은 요약 + 문제해결 도움말
  ① 레시피: 만들 영상 종류를 고르는 칸
  ② 영상  : 본편/인트로/아웃트로/자막 파일을 넣는 칸
  ③ 정보  : 제목·설명·태그(나중에 유튜브에 쓸 정보)
  ④ 내보내기: 「내보내기 시작」 버튼 + 진행 막대 + 결과

  결과가 나오면 그 아래에 다운로드 버튼, (영상이면) "유튜브 업로드" 칸이 생깁니다.


====================================================
5. 레시피 4종 — 언제 무엇을 고르나
====================================================
  ① 토크형 롱폼 (가로 1080p)
     - 말하는 긴 영상(브이로그/강의/리뷰)용.
     - 인트로+본편+아웃트로를 이어붙이고, 자막을 굽고, 음량을 맞춰 1080p로 냅니다.

  ② 쇼츠 세로 (9:16 1080×1920)
     - 유튜브 쇼츠/릴스용 세로 영상.
     - 가로 영상을 세로로 꽉 차게 잘라주고, 큰 자막을 굽습니다.

  ③ 무자막 빠른컷 (가로 1080p)
     - 이미 다른 편집기로 손편집한 클립들을 "빠르게 유튜브용으로 묶기"만 할 때.
     - 자막 없이 정규화 → 결합 → 음량 → 내보내기.

  ④ 썸네일 · 후보 이미지 추출
     - 영상에서 썸네일감/B-roll 후보 이미지를 여러 장 뽑습니다.
     - 자동으로 "정답"을 만드는 게 아니라, 후보를 보여주고 디렉터가 고르는 방식입니다.


====================================================
6. 기본 사용법 — 영상 내보내기
====================================================
가장 많이 쓰는 흐름입니다. (예: 토크형 롱폼)

1) ① 레시피에서 "① 토크형 롱폼"을 클릭합니다.
2) ② 영상에서:
     - "본편 영상"에 영상 파일을 고릅니다. 여러 개를 고르면 고른 순서대로 이어붙입니다.
       (순서가 중요하면 파일명을 1, 2, 3… 으로 정리해두면 편합니다.)
     - 인트로/아웃트로가 있으면 넣고, 없으면 비워둡니다.
     - 자막 파일(.srt 또는 .ass)이 있으면 넣습니다. 없으면 비워도 됩니다.
3) ③ 정보에 제목/설명/태그를 적습니다. (지금 안 적어도 됩니다. 나중에 수정 가능.)
4) ④ 「내보내기 시작」 클릭.
5) 진행 막대가 0% → 100%가 됩니다. (영상 길이·개수에 비례해 시간이 걸립니다.)
6) 끝나면:
     - "🎬 완성 영상 받기(final.mp4)" 로 완성본 다운로드
     - "📦 폴더 전체 받기(zip)" 로 결과 폴더 통째로 받기
     - "📂 결과 폴더 열기" 로 탐색기에서 바로 열기
7) 완성된 final.mp4 를 유튜브에 올리면 끝!
   (앱에서 바로 올리고 싶으면 → 9번 "유튜브에 바로 올리기" 참고)

쇼츠(②)·빠른컷(③)도 같은 방식입니다. 쇼츠는 가로 영상을 세로로 잘라줍니다.


====================================================
7. 결과 폴더 안의 파일들이 뭔가요?
====================================================
영상 내보내기를 하면 outputs 폴더 안에 결과 폴더가 하나 생기고, 그 안에:

  final.mp4          → 완성된 영상 (이걸 유튜브에 올리면 됩니다)
  thumbnail.png      → 영상에서 뽑은 썸네일 후보 1장
  metadata.json      → 제목/설명/태그 정보 (업로드 시 자동 사용)
  description.txt    → 설명란에 붙여넣기 좋게 정리된 설명
  upload_checklist.md→ 발행 전 점검 체크리스트(사람이 읽는 용)
  run_manifest.json  → "무엇을 어떻게 처리했는지" 전부 기록(문제 추적용)
  WARNINGS.txt       → (있을 때만) 색/음량 관련 참고사항

  ※ 후보추출(④)을 하면 candidates/ 폴더에 후보 이미지들 + contact_sheet.png(모아보기)


====================================================
8. 이미지(썸네일/B-roll) 뽑기 + 업스케일 / 배경제거
====================================================
1) ① 레시피에서 "④ 썸네일·후보 이미지 추출" 선택.
2) ② 본편 영상에 영상을 넣고 「후보 이미지 추출 ▶」 클릭.
3) 끝나면 후보 이미지들이 격자로 쭉 나옵니다.
     - 씬이 바뀌는 지점(컷)과, 일정 간격으로 뽑은 장면들이 섞여 나옵니다.
4) 마음에 드는 컷에서:
     - "업스케일" : 화질을 4배로 키웁니다(썸네일 크게 쓸 때). GPU 필요.
     - "배경제거" : 인물/사물만 남기고 배경을 지웁니다. (rembg 설치 시)
     - "원본"     : 그대로 다운로드
   → 처리된 결과는 "결과 내려받기" 링크로 받습니다.

  ※ 업스케일/배경제거는 디렉터가 "고른 1장에만" 적용됩니다(자동 일괄처리 아님).
  ※ 배경제거가 비활성이면, PowerShell에서 한 번:  .\.venv\Scripts\python.exe -m pip install rembg


====================================================
9. 유튜브에 바로 올리기 (선택 기능 · 1회 설정 필요)
====================================================
앱에서 버튼 한 번으로 내 채널에 올리고 싶을 때만 설정하면 됩니다.
설정 전에도 final.mp4 를 유튜브 스튜디오에 직접 끌어다 올리는 건 언제나 가능합니다.

★ 왜 설정이 필요한가요?
  구글의 보안 정책상, "내 채널에 자동으로 올릴 권한"은 본인이 직접
  구글 클라우드 콘솔에서 한 번 켜줘야 합니다. (무료 · 카드 불필요)

────────── (1회) 구글 클라우드 설정 ──────────
  앱 화면의 "유튜브 업로드" 칸에 있는 "설정 안내 보기" 링크
  (또는 creator-toolset\UPLOAD_SETUP.md 파일)에 그림 단계까지 적어두었습니다. 요약:

  STEP 1. https://console.cloud.google.com 접속 → 새 프로젝트 만들기
  STEP 2. "YouTube Data API v3" 검색 → 사용 설정
  STEP 3. "Google Auth Platform"(=OAuth 동의화면)에서:
          - 브랜딩: 앱 이름 + 내 이메일
          - 대상(Audience): 외부(External) + 테스트 사용자에 ★내 유튜브 이메일 추가★
          - 데이터 액세스: ".../auth/youtube.upload" 범위 추가 ★중요★
  STEP 4. "클라이언트(Clients)" → 데스크톱 앱 만들기 → JSON 다운로드
  STEP 5. 받은 파일 이름을  client_secret.json  으로 바꿔서
          creator-toolset\secrets\ 폴더에 넣기 (secrets 폴더는 직접 만드세요)

────────── 인증 (1회) ──────────
  앱에서 영상 하나 내보낸 뒤, 결과의 "유튜브 업로드" 칸에 "🔑 유튜브 계정 인증" 클릭
  → 브라우저 동의창에서 "고급 → 이동 → 허용". ("확인되지 않은 앱" 경고는 본인 앱이라 안전)

────────── 업로드 ──────────
  인증되면 "▶ 내 유튜브 채널에 업로드" 버튼이 켜집니다.
  - 공개 범위: "비공개" 권장 (올린 뒤 스튜디오에서 직접 공개)
  - "예약 공개 시각"을 넣으면(예: 2026-07-01T09:00:00Z) 그 시각에 공개되도록 예약
  - 업로드가 끝나면 영상 링크와 "스튜디오에서 편집" 링크가 뜹니다.

  ★ 꼭 알아둘 점: 개인(미감사) 프로젝트는 업로드가 "비공개"로 잠깁니다. 정상입니다.
    스튜디오에서 1클릭으로 공개하면 됩니다. (공개 자동발행까지 원하면 구글 감사 필요)
  ★ 인증 토큰은 약 7일 후 만료될 수 있습니다. 그때 "인증" 버튼을 한 번 더 누르면 됩니다.

10. 문제가 생겼을 때 (자주 막히는 곳)
====================================================
• 화면이 안 열려요 / "서버 연결 실패"
   → run_server.ps1 가 켜져 있는지 확인. 주소는 http://127.0.0.1:8020

• 상태표시에 "ffmpeg 없음"
   → ffmpeg 미설치. PowerShell에서:  winget install Gyan.FFmpeg  후 서버 재시작.

• "HDR/BT.2020 영상은 지원하지 않습니다"
   → 아이폰 HDR 등은 색이 틀어질 수 있어 일부러 막아두었습니다.
     촬영설정에서 HDR을 끄거나, 일반(SDR)으로 변환 후 넣어주세요.

• 자막 글자가 안 보여요
   → 자막이 .srt 또는 .ass 인지 확인. 한글 폰트는 자동(맑은 고딕)입니다.

• 너무 오래 걸려요
   → 영상 길이·개수에 비례합니다. 진행 막대가 움직이면 정상입니다.

• 업스케일 버튼이 회색(비활성)
   → Real-ESRGAN(ReMaster 프로젝트 bin)이 안 보이거나 GPU 문제. ReMaster bin 폴더 확인.

• 업로드 버튼이 안 보이거나 "인증 필요"
   → 9번 설정을 안 했거나 인증 전입니다. 설정 안내를 따라 하세요.

• "다른 작업이 진행 중입니다"(429)
   → 한 번에 하나씩만 처리합니다. 앞 작업이 끝난 뒤 다시 누르세요.

• 결과가 이상해요
   → 결과 폴더의 run_manifest.json 에 처리 과정이 전부 기록돼 있습니다.
     WARNINGS.txt 가 있으면 참고사항이 적혀 있습니다.


====================================================
11. 자주 묻는 질문 (FAQ)
====================================================
Q. 정말 공짜인가요?
A. 네. 모든 처리는 내 PC에서 무료 오픈소스(ffmpeg 등)로 돕니다. 유튜브 API도 무과금입니다.

Q. 인터넷에 내 영상이 올라가나요?
A. 아니요. 9번 "유튜브 업로드"를 직접 누를 때만 내 채널로 올라갑니다. 그 외엔 전부 로컬.

Q. 여러 영상을 합칠 수 있나요?
A. 네. "본편"에 여러 개를 고르면 고른 순서대로 이어붙입니다.

Q. 화질이 떨어지나요?
A. 고품질 설정(libx264 CRF 20)으로 냅니다. 원본이 좋으면 거의 차이 없습니다.

Q. GPU가 꼭 있어야 하나요?
A. 영상 내보내기는 GPU 없이도 됩니다. 업스케일/배경제거만 GPU가 있으면 좋습니다.

Q. 만든 영상은 어디 있나요?
A. creator-toolset\outputs\ 폴더, 또는 결과 화면의 "결과 폴더 열기" 버튼.


====================================================
12. 알아두면 좋은 팁
====================================================
• 비공개로 올린 뒤 유튜브 스튜디오에서 최종 점검 후 공개하는 습관을 추천합니다.
• 썸네일은 ④ 후보추출로 여러 장 뽑아 업스케일한 뒤 고르면 편합니다.
• 자막은 .ass 로 만들면 글자 크기/위치/색을 더 세밀하게 조절할 수 있습니다.
• 같은 종류 영상을 자주 만들면, 레시피를 직접 만들어 두면(13번) 매번 같은 설정으로 빠르게.
• 결과 폴더의 description.txt 를 그대로 복사해 유튜브 설명란에 붙여넣으면 됩니다.


====================================================
13. 고급 — 레시피 직접 만들기 / 폴더 구조
====================================================
[레시피 직접 만들기]
  recipes\ 폴더에 .json 파일을 하나 더 만들면 새 레시피가 추가됩니다.
  기존 파일(예: 01-talk-longform.json)을 복사해 값만 바꾸세요. 주요 항목:
    "target": { "width":1920, "height":1080, "fps":30, "fill":"pad" }
        fill: "pad"=레터박스(잘림 없음) / "crop"=꽉채우기(쇼츠)
    "subtitles": true/false   (자막 굽기 사용 여부)
    "intro_outro": true/false (인트로/아웃트로 결합 허용)
    "crf": 20                 (작을수록 고화질·큰 용량. 18~23 권장)
    "steps": ["normalize","concat","subtitle_burn","loudnorm","export","package"]
  ※ steps 는 정해진 단어만 쓸 수 있습니다(안전장치). 잘못 적으면 그 레시피는 무시됩니다.

[폴더 구조]
  creator-toolset\
    ├ index.html              화면(UI) + 내장 사용설명서
    ├ main.py                 서버
    ├ recipes\                레시피 4종(JSON) — 직접 편집 가능
    ├ outputs\                결과물이 쌓이는 곳
    ├ secrets\                업로드 자격증명(직접 만든 client_secret.json) — 절대 공유 금지
    ├ UPLOAD_SETUP.md         유튜브 업로드 1회 설정 안내
    └ scripts\                설치/실행 스크립트
