📖 처음이세요? — 1분 사용법

초보자용 안내입니다. 위에서 아래로 ①②③④ 순서대로만 하면 됩니다.

1
레시피를 고르세요. 만들 영상 종류를 고르는 칸입니다. 말하는 긴 영상이면 ①토크형, 세로 쇼츠면 ②쇼츠, 이미 편집된 클립을 합치기만 하면 ③빠른컷, 썸네일감만 뽑으려면 ④후보추출.
2
영상 파일을 넣으세요. 본편은 필수(여러 개 넣으면 순서대로 이어붙입니다). 인트로/아웃트로/자막은 있으면 넣고, 없으면 비워두세요.
3
제목·설명·태그를 적으세요. 나중에 유튜브에 붙여넣을 정보입니다. 지금 안 적어도 되고, 나중에 결과 폴더에서 수정해도 됩니다.
4
「내보내기 시작」을 누르세요. 진행 막대가 100%가 되면, 결과 폴더에 final.mp4(완성 영상)와 썸네일·설명·체크리스트가 함께 생깁니다. 그 final.mp4를 유튜브 스튜디오에 올리면 됩니다. (채널 자동 업로드는 3단계에서 추가 예정)
이 도구가 자동으로 해주는 것 (안 보이지만 중요)
  • 화면 규격 통일 — 서로 다른 해상도/프레임의 클립을 같은 규격으로 맞춰 깨끗하게 이어붙입니다.
  • 음량 자동 정규화 — 유튜브 권장 기준(-14 LUFS)으로 소리 크기를 맞춰, 너무 작거나 큰 소리를 정리합니다.
  • 자막 굽기 — SRT/ASS 자막을 영상에 직접 새겨 어디서 봐도 자막이 나오게 합니다(한글 폰트 자동).
  • 유튜브용 내보내기 — H.264/AAC MP4 + 빠른 시작(faststart)으로, 업로드가 잘 되는 형식으로 저장합니다.
문제가 생기면 (자주 묻는 것)
  • “HDR 영상은 지원하지 않습니다” 라고 나와요 → 아이폰 HDR 등은 색이 틀어질 수 있어 일부러 막아뒀습니다. 촬영 설정에서 HDR을 끄거나, 일반(SDR)으로 변환 후 넣어주세요.
  • 자막 글자가 안 보여요 → 자막 파일이 SRT/ASS 인지 확인하세요. 한글 폰트는 자동(맑은 고딕)입니다.
  • 오래 걸려요 → 영상 길이·개수에 비례합니다. 진행 막대가 멈춘 게 아니라면 정상입니다.
  • 결과가 이상해요 → 결과 폴더의 run_manifest.json 에 무엇을 어떻게 처리했는지 다 기록돼 있습니다(문제 추적용). 참고사항은 WARNINGS.txt.
서버 실행·결과 위치·여러 영상 순서 (조금 더 알고 싶다면)
  • 서버 실행 — 이 화면이 안 열리면 프로젝트 폴더에서 scripts\run_server.ps1 를 실행하고 브라우저로 http://127.0.0.1:8020 에 접속하세요.
  • 처음 한 번 설치 — scripts\setup_windows_desktop.ps1 (파이썬 환경 + 의존성). 위 상태표시줄에 “ffmpeg 없음”이 보이면 ffmpeg 설치가 필요합니다.
  • 결과 위치 — 완료 화면의 「결과 폴더 열기」 버튼, 또는 프로젝트의 outputs/ 폴더에 있습니다.
  • 여러 본편 순서 — 고른 순서대로 이어붙입니다. 순서가 중요하면 파일명을 1, 2, 3… 으로 정리한 뒤 선택하세요.
