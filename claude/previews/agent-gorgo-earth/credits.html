지도 데이터 출처

지형은 실제 부산의 고도 자료를 사용했습니다. 건물·나무·캐릭터는 직접 만든 미니어처 표현이며 실제 건물의 정확한 모양이나 보행 경로를 나타내지 않습니다. 항만 매립지와 해안선은 고도 자료의 시기·해상도에 따라 현재와 차이가 있을 수 있습니다.

지형
Mapzen Terrain Tiles / AWS Open Data.
Terrain data includes SRTM and other public elevation sources. 상세 제공자·라이선스는 Mapzen attribution을 참고하세요. 제공자별 고지 전문과 원본 Terrarium 타일, 재현 스크립트와 변환된 고도 표본을 함께 보관합니다.
