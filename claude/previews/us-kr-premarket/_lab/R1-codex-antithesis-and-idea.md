- **가드레일 위험**: `롱-우위 / 숏-우위 / 관망`은 교육용이라 해도 실전 신호처럼 읽힌다.  
  **수정안**: 출력명을 `상승형 조건 일치`, `하락형 조건 일치`, `혼합`, `데이터 부족`으로 바꾸고 진입·청산 표현을 금지하라.

- **결정론 위반 소지**: “현재 컨텍스트 입력”을 허용하면 사용자가 넣은 임의 값으로 결과가 바뀌어 재현성이 깨진다.  
  **수정안**: 기본은 LEDGER 리플레이 모드로 고정하고, 수동 입력 모드는 `사용자 입력·검증 안 됨` 워터마크를 강제하라.

  **수정안**: 유사 사례는 “정확히 어떤 날짜가 비슷했는지”만 보여주고, 승률·확률·예상수익률은 표시하지 말라.

- **블랙박스화 위험**: 점수 가중치가 Claude가 정한 휴리스틱이면 투명 규칙 기반이라는 주장과 충돌한다.  
  **수정안**: 규칙을 `rules.json`으로 분리하고, 각 점수의 수식·임계값·사용 필드를 화면에 노출하라. 임계값은 LEDGER 분위수 또는 명시적 고정값만 허용하라.

  **수정안**: 캘린더 기반 이벤트 게이트와 SOXL/SOXS inverse sanity check를 추가하고, 이벤트일에는 점수보다 “근거 부족/변동성 경고”를 우선 표시하라.

## CODEX IDEA (C2b) — 독립 아이디어 1개

### 0%선 전환 리플레이어 — `flip-replay/`

- **한 줄 컨셉**: 당일 0%선 양전·음전 전환 기록을 리플레이해 “방향이 맞아도 체결이 어려웠던 장”과 “깨끗하게 밀어준 장”을 구분하는 단타 실행 품질 도구.
- **핵심 패널**:
  - 전환 타임라인: 종목·날짜별 양전/음전 시각, 세션, 가격, 전일 종가 대비 %.
  - 휩쏘 지수: 총 flip 수, 본장/시간외 flip 분리, 첫 전환 방향, 마지막 전환 방향, 종가 endState.
  - 실행 난이도 라벨: `Clean trend`, `Opening reversal`, `Zero-line chop`, `Late reclaim/fade`.
  - 계획 스트레스 테스트: 사용자가 “롱/숏 계획”만 입력하면 해당 방향에 불리한 전환 횟수와 첫 불리 전환 시각을 표시.
  - 미·한 릴레이 비교: SOXL/SOXS 시간외 전환과 다음 한국장 삼성전자·SK하이닉스 본장 전환을 나란히 비교.
- **입력**:
  - 종목: `samsung`, `hynix`, `soxl`, `soxs`
  - 날짜
  - 선택 입력: 계획 방향, 고위험 flip 기준값, 세션 필터
- **출력**:
  - 리플레이 차트, 전환 표, 휩쏘 점수, 실행 난이도 라벨, 복기 문장.
  - 단, “매수/매도”가 아니라 “이 과거 장은 체결 난이도가 높았다/낮았다”로만 표현.
- **LEDGER 계산 소스**:
  - `kospi.*[].open/high/low/close/chgPct/flips.crossings`
  - `us.soxl[]`, `us.soxs[]`의 `regOpen/regClose/regChgPct/extOpen/extClose/extVsRegPct/extChgPct/flips.crossings`
  - 파생값: `gapPct`, `totalFlipCount`, `regFlipCount`, `extFlipCount`, `firstFlipDir`, `lastFlipDir`, `flipClusterCount`, `endState`, `closeDirectionMatch`.
- **왜 보완적인가**:
  - C1은 레벨·사이징·히트맵 중심이고, C2a는 당일 편향 평가다. `flip-replay/`는 그다음 단계인 “실제로 그 편향을 체결할 만한 장이었는가”를 복기한다.
  - 박사의 단타 스타일에서 치명적인 문제는 방향 오판만이 아니라 0%선 주변 휩쏘에 당하는 것이다. 이 도구는 실측 5분 flip 기록만으로 체결 난이도를 재현하므로 정적 HTML/JS에서 결정론적으로 구현 가능하다.

## CODEX ANTITHESIS (R1) — Claude 설계 비평

### C1 — `desk/`

- **결정론 위반 소지**: “전일 OHLC에서 피벗/ATR 계산”이라고 했지만 LEDGER의 미국 SOXL/SOXS에는 고가·저가가 없고 `regOpen/regClose` 중심이다.  
  **수정안**: 고가·저가가 있는 한국 종목에만 피벗/ATR을 활성화하고, 미국 ETF는 검증된 high/low가 추가되기 전까지 비활성 상태로 표시하라.

- **소표본 일반화 위험**: 6월 1~12일, 특히 한국은 약 8거래일 수준인데 상관·베타·오버나잇 전이를 데스크 핵심 신호처럼 보이면 과학적 근거가 약하다.  
  **수정안**: 모든 상관·전이 카드에 `n`, 표본기간, “탐색용” 배지를 붙이고, `n < 20`이면 예측 문구와 순위화를 금지하라.

- **가드레일 위험**: 포지션 사이저가 “주수·목표가”를 직접 계산하면 실제 매매 지시처럼 보일 수 있다.  
  **수정안**: 이름을 “리스크 계산기”로 바꾸고, 기본 진입가·손절가를 제공하지 말라. 사용자가 직접 입력한 값에 대해 손실액·R배수만 계산하라.

- **라이브 차트 리스크**: TradingView 위젯과 `LIVE FEED CONNECTED` 문구는 정적·재현가능 대시보드 원칙과 충돌한다.  
  **수정안**: 라이브 위젯은 “외부 참고 화면, 계산 미사용”으로 분리하고, 랜딩의 라이브 표현은 실제 데이터 연결 범위와 일치시켜라.

- **단타 실전 누락**: 레벨과 사이징은 있으나 “오늘 장이 휩쏘장인지”, “첫 30분 추격이 위험한지” 같은 체결 품질 판단이 없다.  
  **수정안**: C1에는 C2b `flip-replay/`로 연결되는 실행 품질 요약만 넣고, 본문에서는 데스크를 과밀하게 만들지 말라.
