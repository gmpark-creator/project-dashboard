# Chart Playbook · R2 진행 중 전제 정정 (박사 하달 2026-08-13)

## 박사 원문
> SOXL로 체결을 하지 않는다. 지금 너희가 준 정보들을 바탕으로 **새로운 종목들을 발굴해내는 것**이다. 차트에 맞게, 밸류에이션에 맞게, **밸류에이션은 내가 찾고, 차트는 너희가 주는 정보들을 토대로 새롭게 분석할 것**이다. **SOXL이라는 종목 하나에 매몰되지 않도록 해라.**

## 이 정정이 덮어쓰는 것
- **R1 전 라운드의 종목 전제** 및 `_DIRECTIVE.md`(2026-06-15)의 "미국 반도체 SOXL 단타" 전제.
- `_DIRECTIVE.md`의 비종목 조항(연구·교육용 고지, 협업 규율, 저장 규칙)은 그대로 유효.

## 강제되는 설계 변경 5건
1. **종목 중립(instrument-agnostic) 프레임.** SOXL/SOXS는 주인공에서 강등 → **「레버리지 ETF는 이 프레임을 그대로 적용하면 깨진다」는 예외 경고 사례**로만 등장.
2. **목적 전환:** 특정 종목 매매 보조 → **종목 발굴(스크리닝) 프레임.**
3. **역할 확정:** 밸류에이션 = 박사(우리 범위 밖, 재무·목표주가·적정가치 서술 금지) / 차트·거래량·변동성·유동성 = 우리.
4. **쟁점 소멸:** Codex R1 반박 10("SOXL 구조 분석 금지")과 Claude R2-v1 반박 B("박사가 실제 체결하는 종목이 SOXL이므로…")는 **양쪽 다 철회**. 후자는 전제가 거짓이었음.
5. **신설 축 요구:** 박사가 밸류에이션으로 고른 후보에 대해 **「이 종목이 차트적으로 어느 스타일에 적합한가 / 어디에도 부적합한가」**를 판정하는 축 (→ R2 §3-B, 8축 필터).

## 절차 조치
- R2 v1은 오염된 전제(반박 B)로 이미 `codex exec` 실행 중이었으므로 **중단(TaskStop) 후 v2 재발행**. 결과를 받아 R3에서 정정하는 대신 중단을 택한 이유: 이 프로젝트는 `_DIRECTIVE.md`부터 SOXL 중심이라 Codex가 종목 종속으로 사고할 구조적 관성이 있고, 전제 정정을 R2 본문에 박아야 R3까지 흔들리지 않는다.
- 신규 페이지 예시는 **익명 심볼(`종목 A`)·상품군(개별주/ETF/레버리지 ETF)** 표기. 실존 종목명은 레버리지 예외 경고에서만 사용.

## 신설 8축 (R2 §3-B)
A1 유동성(일평균 거래대금) · A2 스프레드 · A3 변동성(ATR%) · A4 거래량 일관성 · A5 갭 빈도·크기(**스윙 적합성 핵심**) · A6 구조 명료성 · A7 섹터 상대강도(Codex R1 지적 6의 승격) · A8 상품 구조(레버리지·인버스 = 예외군)

출력은 **적합 / 부적합 / 판정 불가** 3값. **종목 추천·매수의견·목표주가 금지.**
