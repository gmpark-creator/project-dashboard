# 02 · 화면 구성안 (Screens)

디렉터 요청 ② 항목. 6개 화면 각각: **목적 → 와이어프레임(ASCII) → 핵심 컴포넌트 표 → 상태 → 필요 데이터**. 실물 목업은 [prototype/index.html](../prototype/index.html).

> 공통 셸: 좌측 슬림 레일(프로젝트/생성/라이브러리/설정) + 상단 컨텍스트 바(프로젝트명·자동저장·크레딧 잔액) + 우측 작업 영역. 다크 SaaS 톤. **모든 사용자 텍스트 한국어.**

---

## 화면 1 · 프로젝트 대시보드 (Project Dashboard)

**목적:** 진행 중/완료 영상 한눈에, "새 영상" 시작점. 재진입 허브.

```
┌─ Cutpilot ───────────────────────────────────── 크레딧 1,240 ⚡ ─ 설정 ─┐
│ [+ 새 영상 만들기]            검색▢   필터: 전체 ▾  목적 ▾  상태 ▾       │
├──────────────────────────────────────────────────────────────────────┤
│ 이어서 작업하기                                                         │
│ ┌────────────┐ ┌────────────┐ ┌────────────┐                          │
│ │▣ 썸네일     │ │▣ 썸네일     │ │  + 빈 카드   │   ← 진행중(검토 단계)     │
│ │ 봄 신상 광고 │ │ 카페 쇼츠    │ │  새로 시작   │                          │
│ │ 광고·검토중 │ │ 쇼츠·생성중◔│ │            │                          │
│ │ 8컷 · 60%   │ │ 6컷 · 생성2/6│ │            │                          │
│ └────────────┘ └────────────┘ └────────────┘                          │
│ 완료된 영상                                                             │
│ ┌────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐           │
│ │▶ 앱소개 v3  │ │▶ 매물투어   │ │▶ 브랜드필름 │ │▶ 교육-3강   │           │
│ │ 완료·MP4    │ │ 완료·3컷셋  │ │ 완료        │ │ 완료        │           │
│ └────────────┘ └────────────┘ └────────────┘ └────────────┘           │
└──────────────────────────────────────────────────────────────────────┘
```

| 컴포넌트 | 설명 | 데이터 |
|---|---|---|
| 새 영상 CTA | 가장 눈에 띄는 1차 액션 | — |
| 프로젝트 카드 | 썸네일·제목·목적뱃지·상태·진행률(컷 N/M) | `Project{id,title,intent,status,progress,thumb,updatedAt}` |
| 상태 인디케이터 | 검토중/생성중◔/렌더중/완료/실패 | `status`, 생성중이면 `done/total` |
| 필터·검색 | 목적·상태·텍스트 | 클라이언트 필터 |
| 이어서/완료 구획 | 진행중을 위로(재진입 우선) | `status != done` 정렬 |

- **상태:** 빈 상태(첫 방문)=큰 "첫 영상 만들기" + 6목적 예시 갤러리. 생성중 카드는 라이브 진행률(폴링/스트림).
- **클릭 시:** 진행중→마지막 단계 화면으로, 완료→화면6(또는 재편집).

## 화면 2 · 새 영상 생성 (New Video — Idea Wizard)

**목적:** 아이디어 입력 + 목적 선택을 **한 흐름**으로. 플로우 ①②.

```
┌─ 새 영상 만들기 ────────────────────────────────── ✕ ─┐
│  무엇을 만들까요?                                       │
│  ┌─────────────────────────────────────────────────┐ │
│  │ 예) 우리 카페 신메뉴 딸기라떼를 소개하는 인스타     │ │
│  │     쇼츠. 산뜻하고 통통 튀는 느낌.                  │ │
│  └─────────────────────────────────────────────────┘ │
│  📎 이미지·제품URL·대본 첨부(선택)                       │
│  빠른 예시:  [신상 광고] [앱 소개] [매물 투어] [교육]    │
│                                                         │
│  목적 선택  (화면비·길이·톤이 자동 맞춰집니다)           │
│  ┌─쇼츠──┐┌─광고──┐┌─앱소개─┐┌─공간──┐┌─교육──┐┌─캠페인┐│
│  │ 9:16  ││ 9:16  ││ 16:9  ││ 16:9  ││ 16:9 ││ 16:9 ││
│  │ 15s   ││ 30s   ││ 60s   ││ 90s   ││ 60s  ││ 60s  ││
│  │ ●선택 ││       ││       ││       ││      ││      ││
│  └───────┘└───────┘└───────┘└───────┘└──────┘└──────┘│
│  ▸ 고급 옵션 (화면비·길이·티어 수동) — 접힘             │
│                                                         │
│        [알아서 만들어줘(Express)]   [스토리보드 만들기 →]│
└─────────────────────────────────────────────────────────┘
```

| 컴포넌트 | 설명 | 데이터 |
|---|---|---|
| 아이디어 입력 | 멀티라인 + placeholder 예시 | `idea:string` |
| 첨부 | 이미지/URL/대본 → 요구플래그 세팅 | `attachments[]`, `script?` |
| 예시 칩 | 빈 입력 방지(P3) | 프리셋 문구 |
| 목적 카드 6종 | 택1, 비율·길이·티어 프리셋 표시 | `intent`, [템플릿 기본값](04-templates.md) |
| 고급 옵션(접힘) | 비율/길이/티어/엔진선호 수동 | `advanced{aspect,duration,tier,enginePref}` (P1: 기본 숨김) |
| 2개 CTA | Express(전자동) / 스토리보드(단계별) | 플로우 분기 |

- **상태:** 입력 비어도 칩으로 시작 가능. 첨부 시 해당 요구플래그 미리보기 배지.
- **검증:** 목적만 필수(아이디어 비면 칩 권유). 모델·파라미터는 절대 강요 안 함.

## 화면 3 · 스토리보드 / 샷 리스트 (Storyboard)

**목적:** 자동 분해된 Scene/Shot을 검토·수정. 플로우 ③. **생성 전 "설계도" 확정 단계.**

```
┌─ 봄 신상 광고 · 스토리보드 ──────── 4 씬 · 9 컷 · 약 30s ── [전체 생성 ▶ 90⚡]─┐
│ 씬 1 · 카페 외경 (낮)                                          [+ 컷] [씬 설정]│
│  ┌─컷1.1───────────┐ ┌─컷1.2───────────┐                                    │
│  │ 와이드·햇살 외경 │ │ 도어 푸시인     │   샷 카드: 미리보기 자리            │
│  │ 3s · 🎬자동      │ │ 2s · 🎬자동      │   + 프롬프트 요약 + 길이 + 엔진뱃지 │
│  │ [프롬프트 ✎][⋯] │ │ [프롬프트 ✎][⋯] │   (✎=SAEC 필드 편집, ⋯=복제/삭제)  │
│  └─────────────────┘ └─────────────────┘                                    │
│ 씬 2 · 음료 클로즈업 (실내)                                                   │
│  ┌─컷2.1───────────┐ ┌─컷2.2───────────┐ ┌─컷2.3───────────┐                 │
│  │ 딸기라떼 히어로  │ │ 빨대 꽂기 ECU   │ │ 한 모금 리액션  │  ← 인물 일관 🔒 │
│  └─────────────────┘ └─────────────────┘ └─────────────────┘                 │
│ … 씬 3 사용 장면 · 씬 4 CTA 엔드카드 …                                        │
│ 우측 패널: [장면 추가] [순서 변경=드래그] [캐릭터 레퍼런스 🔒] [내레이션 대본] │
└────────────────────────────────────────────────────────────────────────────┘
```

| 컴포넌트 | 설명 | 데이터 |
|---|---|---|
| 씬 헤더 | 씬 제목·장소/시간·컷수 | `Scene{title,setting,timeOfDay}` |
| 샷 카드 | 프롬프트 요약·길이·엔진뱃지·상태 | `Shot{id,promptDraft,durationSec,requirements,engineHint}` |
| 프롬프트 편집(✎) | SAEC 필드 폼(피사체/동작/환경/카메라/조명/스타일) | `Shot.saec{...}` ([템플릿 스키마](04-templates.md)) |
| 드래그 정렬 | 씬/컷 순서 변경 | `order` |
| 캐릭터 레퍼런스🔒 | 일관 유지 대상 등록(이미지/첫 Take 프레임) | `Project.characters[]` |
| 전체 생성 버튼 | 비용(크레딧) 인라인 표시(P6) | 합산 비용 추정 |

- **상태:** 분해 직후=초안. 컷별 "🎬자동"=라우팅이 엔진 자동결정(엔진명 비노출, 뱃지는 "고품질/빠른" 같은 티어 의미).
- **편집은 가볍게:** 카드 추가/삭제/드래그 + 프롬프트 폼. 대본 모드면 대본↔샷 양방향 동기.

## 화면 4 · 생성 결과 비교 (Compare & Select)

**목적:** 컷마다 후보(Take) 비교·선택. 플로우 ④⑤. **앱의 심장.**

```
┌─ 봄 신상 광고 · 컷 검토 ──────── 진행 7/9 생성완료 ── [고품질로 모두 확정 →]─┐
│ 좌측 컷 목록            │ 컷 2.1 · 딸기라떼 히어로                            │
│  ✓ 1.1 외경            │ ┌──────────┐ ┌──────────┐ ┌──────────┐            │
│  ✓ 1.2 도어            │ │  A안 ▶   │ │  B안 ▶   │ │  C안 ▶   │            │
│  ▶ 2.1 히어로 ◀검토중  │ │ (재생)    │ │ (재생)    │ │ (재생)    │            │
│  ◔ 2.2 빨대 생성중     │ │ 빠른미리뷰│ │ 빠른미리뷰│ │ 빠른미리뷰│            │
│  ⚠ 2.3 리액션 모션흔들 │ │ ●이걸로  │ │ 이걸로    │ │ 이걸로    │            │
│  · 3.1 …               │ └──────────┘ └──────────┘ └──────────┘            │
│                        │ [↻ 이 컷 다시] [✂ 이 부분만 다시ⓘ] [✨ 게시용 품질로 다듬기 12⚡]│
│                        │ 프롬프트: "딸기라떼 클로즈업, 김 모락…" [✎ 손보기]   │
│                        │ ⚠ 자동검사: 2.3 모션 흔들림 의심 → 다시 생성 권장     │
│                        │ ↻ 2.2는 다른 방식으로 다시 시도 중 (이전 후보 보존)   │
└────────────────────────────────────────────────────────────────────────────┘
```

| 컴포넌트 | 설명 | 데이터 |
|---|---|---|
| 컷 목록(좌) | 상태 아이콘(✓선택/▶검토/◔생성중/⚠경고) | Shot별 `status`,`qualityFlags` |
| Take 비교 그리드 | 2~3개 후보 동시 재생·호버 자동재생 | `Take{id,videoUrl,tier,engineUsed(내부),metrics}` |
| "이걸로" 선택 | Take를 Shot의 final로 | `Shot.selectedTakeId` |
| 다시/부분 다시 | 전체 재생성 vs **가능한 최소 범위 재시도**(capability-gated, 미지원 시 shot 폴백·이전 Take 보존) ⓘ툴팁 | `regenerate(scope: shot\|segment)` |
| 게시용 품질로 다듬기 | 선택 Take를 게시용 고품질로 다시 다듬기. **내부 실행=재생성/보정/업스케일 자동 선택**(사용자 비노출), 비용 표시(P2·P6) | `upgrade(takeId)` → final_regenerate\|enhance\|render_upscale |
| 자동 품질배지 | ⚠경고 + 권장 액션 | [품질기준 자동검사](05-quality-criteria.md) |

- **상태:** 부분완료 우선(생성된 컷부터 검토 가능). 모델명 절대 비노출 — "A안/B안", 티어는 "빠른 미리보기/고품질".
- **선택 보조:** 미선택 컷은 품질점수 최고 Take 자동 추천(사용자는 바꾸기만).

## 화면 5 · 간단 편집 / 타임라인 (Assemble & Polish)

**목적:** 선택 컷 합치기 + 자막/BGM/보이스. 플로우 ⑥. **대화형 우선, 타임라인은 보조.**

```
┌─ 봄 신상 광고 · 다듬기 ────────────────────────── [내보내기 →]─┐
│ 미리보기 플레이어 (선택 컷 이어붙인 풀영상)                      │
│  ┌────────────────────────────────────────────┐               │
│  │              ▶  00:12 / 00:30                │               │
│  └────────────────────────────────────────────┘               │
│ 대화형 편집 (Magic Box)                                         │
│  💬 "마지막에 로고 3초 넣어줘 / BGM 더 신나게 / 자막 키워줘"     │
│  빠른 토글: [자막 ✓] [BGM ✓ 산뜻팝▾] [내레이션 ✓ 보이스A▾] [전환 부드럽게]│
│ ▾ 타임라인 (고급, 접힘)                                          │
│  🎬 [1.1][1.2][2.1][2.2][2.3][3.1]…   ← 클립 드래그/트림        │
│  🔊 ▁▂▃ BGM ─────────────────────────                          │
│  🎙 내레이션 ───  💬 자막 ▢▢ ▢▢ ▢                              │
└────────────────────────────────────────────────────────────────┘
```

| 컴포넌트 | 설명 | 데이터 |
|---|---|---|
| 풀영상 미리보기 | 선택 Take 순서대로 스티치 재생(클라이언트 가편) | `Project.selectedTakes[]` |
| Magic Box(대화) | 자연어 편집 명령 → 액션 매핑(P4) | `editCommand:string → ops[]` |
| 자막 | 자동 STT/대본 기반 생성·스타일 | `captions[]{t0,t1,text,style}` |
| BGM | 추천 트랙·자동 더킹(보이스 우선) | `bgm{trackId,gain,duck}` |
| 보이스/내레이션 | TTS 또는 사용자 보이스, 컷 싱크 | `voiceover{voiceId,scriptRef}` |
| 타임라인(접힘) | 클립 트림·전환·오디오 레인(고급) | 위 데이터의 시간축 뷰 |

- **원칙:** 비전문가는 토글+대화만으로 완성. 타임라인은 *원하는 사람만* 펼침(P4). 자막/BGM/보이스는 **자동 초안 후 미세조정**.
- **백엔드 요구:** 실제 합성·믹스·번인은 Render Job(화면6). 여기선 "편집 의도(EDL 유사 구조)"만 만들어 넘김.

## 화면 6 · 내보내기 / 렌더 상태 (Export & Render Status)

**목적:** 최종 MP4 굽기 + 진행/완료. 플로우 ⑦.

```
┌─ 내보내기 ──────────────────────────────────────────┐
│ 형식                                                  │
│  해상도:  [720p] [●1080p] [4K · 고해상도]              │
│           (4K=지원 시 직접·아니면 업스케일. 기본 720/1080)│
│  길이컷:  [✓ 6s 훅] [✓ 15s 표준] [✓ 30s 풀]  (다중)   │
│  비율:    9:16 (원본) → 파생: [16:9] [1:1]            │
│  자막:    [번인] [별도 .srt] [둘 다]                  │
│  예상: 약 2분 · 48⚡                                   │
│            [내보내기 시작 ▶]                          │
├──────────────────────────────────────────────────────┤
│ 렌더 진행                                             │
│  1080p 30s ████████░░ 82% · 컷 합성→오디오 믹스→인코딩 │
│  1080p 15s ✓ 완료  [▶ 미리보기][⬇ 다운로드][공유 링크] │
│   720p  6s ✓ 완료  [⬇]                                │
│  실패 시: [재시도] (이전 단계 산출물 보존)             │
└──────────────────────────────────────────────────────┘
```

| 컴포넌트 | 설명 | 데이터 |
|---|---|---|
| 형식 선택 | 해상도·길이컷(다중)·비율파생·자막형식 | `ExportSpec{res,cuts[],aspects[],caption}` |
| 비용/시간 추정 | 시작 전 명시(P6) | 추정 API(백엔드) |
| 렌더 진행 | Job별 단계·진행률(합성→믹스→번인→인코딩→업스케일) | `RenderJob{id,stage,progress,status,outputUrl}` |
| 결과 액션 | 미리보기/다운로드/공유링크 | `outputUrl`, 공유는 백엔드 |
| 실패 복구 | 재시도(무손실) | `retry(renderJobId)` |

- **상태:** 다중 길이컷 = 다중 RenderJob 병렬, 각각 독립 진행/완료(P: 부분완료 우선).
- **완료 후:** 화면1 대시보드에 "완료" 카드로 반영 + "재편집/복제로 새 버전".
