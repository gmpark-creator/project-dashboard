# 12 · Image Maker 화면 설계 (보조)

[11-visual-maker-expansion.md](11-visual-maker-expansion.md)의 Image Maker 화면 상세. 구현 미수정·제안만. **모델명/엔진명 비노출**, 목적 중심.

> **정합(types.ts 실제):** UI 목적 → `ImageMakerPurpose`(`photoreal`·`product`·`character`·`background`·`style`·`poster`·`thumbnail`·`transparent`). 매핑: 사진급 실사=photoreal · 제품=product · 인물 참조=character · 배경=background · 스타일 참조=style · 로고/포스터=poster · 썸네일=thumbnail · 배경 제거(투명)=transparent. 후보 품질 `ImageVariant.scoreLabel`은 **3종(추천/안정적/확인 필요)**, **실패는 `status="failed"`로 표시**(별도 라벨 없음). `ImageJob`에 tier·referenceAssetIds는 현재 타입에 없음(11 §4 제안 참조).

## 1. Image Maker 흐름
```
입력(프롬프트·비율·스타일·목적·참조) → [후보 생성 N⚡] → 후보 A/B/C/D 비교 → 선택
   → Asset Library 저장(category·권리)  AND/OR  Video Maker로 보내기(역할)
```
편집 보조: 배경 제거(투명) · 재생성 · 변형(variation). 영상과 분리된 독립 화면.

## 2. Image Maker 메인 화면
```
┌ 🖼 Image Maker ───────────────────────────── 1,240⚡ ─┐
│ 무엇을 만들까요?                                        │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 예) 딸기라떼 제품컷, 흰 배경, 부드러운 그림자        │ │
│ └──────────────────────────────────────────────────┘ │
│ 예시: [제품컷] [인물컷] [배경컷] [스타일컷] [썸네일] [로고/포스터]│
│                                                        │
│ 용도(목적)  ● 제품 이미지  ○ 사진급 실사  ○ 인물 참조  ○ 스타일 참조  ○ 로고/포스터  ○ 썸네일  ○ 배경 │
│ 비율 [1:1 ▾]   스타일 [사진 ▾]   품질 [저비용 시안 ▾ / 고품질]        │
│ 참조 이미지(선택): [+ 라이브러리/업로드]  [이 제품처럼🔒] [이 인물로🔒]   │
│ 후보 수 [4 ▾]                                          │
│            [후보 생성  12⚡]                            │
└────────────────────────────────────────────────────────┘
```
| 컴포넌트 | 역할 / UX 규칙 |
|---|---|
| 프롬프트 입력 | 자유 텍스트 + placeholder, 모델/파라미터 없음. 빈값 제출 차단(인라인 오류) |
| 예시 칩 | 목적별 빠른 시작(빈 입력 방지) |
| **용도(목적)** | 7종 택1 — `purpose`. 목적이 category·기본 비율·라우팅 힌트 결정. **엔진명 대신 목적** |
| 비율 | 1:1·9:16·16:9·4:5 (영상 Aspect 정합) |
| 스타일 | 사진·일러스트·3D·미니멀·시네마틱 (체감 라벨) |
| 품질 티어 | 저비용 시안 / 고품질 (영상 tier와 동일 추상화) |
| 참조 이미지 | Library/업로드에서 추가, 역할 배지(제품/인물/스타일) |
| 후보 수 | 2~4 (기본 4 = A/B/C/D) |
| 생성 버튼 | "후보 생성 N⚡" — **버튼 위 ⚡ 비용**(후보 수×단가) |

## 3. Image 후보 비교 화면 (`ImageCompareGrid`)
```
┌ 후보 비교 · 딸기라떼 제품컷 ───────────────────────────┐
│ ┌ A안 ┐ ┌ B안 ┐ ┌ C안 ┐ ┌ D안 ┐                       │
│ │ 🖼  │ │ 🖼  │ │ 🖼  │ │ 🖼  │   ← 비율 유지 썸네일      │
│ │추천 │ │안정 │ │확인 │ │ 실패│   ← 체감 라벨(숫자X)      │
│ │[이걸로]│[이걸로]│[이걸로]│[다시]│                       │
│ └─────┘ └─────┘ └─────┘ └─────┘                       │
│ [🔍 확대 비교]  [↻ 다른 후보 더 12⚡]  [✂ 배경 제거]      │
│ 선택 후: [Asset Library에 저장]  [Video Maker로 보내기 ▾]│
└────────────────────────────────────────────────────────┘
```
| 규칙 | 내용 |
|---|---|
| 후보 표시 | 2~4 나란히, 비율 유지(영상 take와 달리 정지 이미지) |
| 품질 라벨 | `scoreLabel` 추천/안정적/확인 필요(3종, 숫자X — R3-04 정합). 실패 후보는 `status="failed"`로 "재시도 필요" 표시 |
| 확대 비교 | 클릭 시 1:1 확대·좌우 스와이프(디테일 비교) |
| 선택 | "이걸로"→해당 후보 선택, 나머지 보존 |
| 더 생성 | "다른 후보 더 N⚡"(이전 후보 보존) |
| 배경 제거 | 선택 이미지 투명 PNG 변형(편집 보조) |
| 저장 | ImageAsset 승격(category·권리 입력 모달) |
| 보내기 | "Video Maker로 보내기" → 대상 Project/Shot + **역할** 선택([11 §6]) |
| 실패 후보 | "재시도 필요" 오버레이, 선택 불가, [다시] |
| 모바일 | A/B/C/D 가로 스와이프 또는 2×2(390px에서 1열 과대 금지 — R4-04 교훈) |

## 4. 이미지 편집 보조
| 기능 | UX | 비고 |
|---|---|---|
| 배경 제거 | "배경 지우기(투명)" 1클릭 → 투명 PNG 변형 저장 | 제품컷/로고 활용 |
| 변형(variation) | 선택 이미지 기반 비슷한 후보 더 | 참조 기반 재생성 |
| 재생성 | 프롬프트 수정 후 다시 | 이전 후보 보존 |
| 비율 재구성 | 다른 비율로 확장/크롭 | 영상 비율 맞춤 |

(고급 픽셀 편집은 범위 밖 — MVP는 생성·배경제거·변형 중심.)

## 5. "Video Maker로 보내기" 미니 플로우
```
[Video Maker로 보내기 ▾]
 → 대상: ○ 새 영상 만들기   ○ 기존 프로젝트 [딸기라떼 쇼츠 ▾] → 컷 [2.1 ▾]
 → 역할: ○ 영상 참조  ○ 첫 프레임  ○ 스타일만  ○ 인물 유지  ● 제품 유지  ○ 배경 유지
 → [참조로 추가]  (Shot.referenceImageIds + directionSpec.references 기록)
```
- 새 영상이면 Video Maker 새 프로젝트로 이동하며 해당 이미지가 첫 참조로 프리셋.
- 기존 프로젝트면 지정 Shot에 참조 추가 후 비교/연출 화면으로.

## 6. Acceptance Criteria (Image Maker)
- IM-AC-1 목적 7종·비율·스타일·티어 선택 후 "후보 생성"→`ImageJob` 생성, `ImageVariant` A~D 상태머신 진행.
- IM-AC-2 후보 "이걸로"→`ImageAsset` 승격(category=목적 매핑)·라이브러리 저장, 미선택 보존.
- IM-AC-3 "다른 후보 더"→기존 후보 보존하고 신규 variant 추가.
- IM-AC-4 "배경 제거"→투명 변형이 새 ImageAsset(또는 변형)으로 저장.
- IM-AC-5 "Video Maker로 보내기"→대상 Shot의 `referenceImageIds`에 추가 + 선택 역할이 `directionSpec.references`에 기록.
- IM-AC-6 빈 프롬프트 제출 차단(인라인 오류, R3-14 정합).
- IM-AC-7 비용 액션(후보 생성·고품질·더 생성)에 ⚡ 인라인. 화면 내 모델명 0.
- IM-AC-8 모바일 390px 후보 비교 가로 오버플로 0, 한 비교 1~1.5 스크롤 내.
