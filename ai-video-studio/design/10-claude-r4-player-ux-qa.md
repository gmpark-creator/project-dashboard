## 3. 동영상 재생기 UX 설계 (R4 본론)

세 가지 플레이어 + 공통 컨트롤. **모델명 비노출**, 비전문가 용어, 상태 오버레이.

### 3.0 공통 재생 컨트롤 (`PlayerControls`)
| 요소 | 동작 | 비전문가 카피 |
|---|---|---|
| 재생/일시정지 | space/탭 | ▶ / ⏸ |
| 스크럽바 | 드래그·클릭 이동, 버퍼 표시 | (시간 `0:03 / 0:15`) |
| 음소거/볼륨 | 토글 | 🔇/🔊 |
| 전체화면 | 토글 | ⤢ |
| 해상도 배지 | 표시만 | "1080p" (모델명 X) |
| 상태 오버레이 | 생성중=스피너+"만드는 중", 실패=⚠+"다시 시도", 준비중=썸네일 | — |
| 반복 | 짧은 클립 자동 루프(옵션) | "반복" |

**AC(공통):** 키보드 접근(space/←→/f/m)·aria-label 한국어 · 모바일 탭 컨트롤 · 자막 트랙 토글 · poster(첫 프레임)로 즉시 시각 피드백 · 로딩 실패 시 "다시 불러오기"(서명 URL 갱신, R3 expired media와 정합).

### 3.A 컷별 후보 비교 플레이어 (`TakeComparePlayer`) — compare 화면
```
데스크탑(컷 N · 제목)                              [상태 배지]
┌── A안 ──────┐ ┌── B안 ──────┐ ┌── C안 ──────┐
│ ▶ 영상      │ │ ▶ 영상      │ │ ▶ 영상      │   ← 9:16/16:9, poster→재생
│ (동기 재생) │ │            │ │            │
│ 0:00/0:03   │ │            │ │            │
│ 추천 ·1080p │ │ 안정적     │ │ 확인 필요  │   ← 체감 품질 라벨(숫자X)
│ [● 이걸로]  │ │ [이걸로]    │ │ [이걸로]    │
└─────────────┘ └────────────┘ └────────────┘
[↻ 이 컷만 다시 12⚡] [✂ 가능한 좁은 범위로 다시 ~12⚡] [✨ 게시용 품질로 다듬기 22⚡] [다듬기 →]
```
| 규칙 | 내용 |
|---|---|
| 동기 비교 | 한 후보 재생 시 **"3개 동시 재생" 토글** 제공(같은 타임코드 비교). 기본은 호버/탭 단독 재생 |
| 선택 | done 후보만 "이걸로" 활성, 선택 시 "선택됨"·카드 강조 |
| 실패 후보 | 재생 불가, "다시 시도 필요" 오버레이, 카드 비활성 |
| 생성중 | 스피너+진행률, 카드 비활성 |
| 버튼 위계 | 실패 컷=「이 컷만 다시」 primary(R3-07 유지). 정상=「게시용 품질로 다듬기」 primary |
| 모바일 | **A/B/C 가로 스와이프 또는 탭 전환**(R4-04) — 3개 세로 스택 금지 |

**AC:** ①done 후보 클릭 시 영상 재생 ②"동시 재생" 토글 시 3 후보 동일 타임코드 동기 ③"이걸로"→`selectTake`·즉시 강조 ④실패/생성중 후보 재생 불가+상태 오버레이 ⑤모바일 390px 한 컷 비교가 1~1.5 스크롤 ⑥재생 UI에 모델명 0.

### 3.B 시퀀스 프리뷰 플레이어 (`SequencePreviewPlayer`) — 다듬기 화면
선택된 컷들을 **이어서** 재생 + 컷 세그먼트 타임라인.
```
┌─ 미리보기(선택 컷 N개 이어보기) ─────────┐
│         ▶  0:08 / 0:15                    │
└──────────────────────────────────────────┘
[컷1][컷2][컷3][컷4][컷5]…   ← 세그먼트 타임라인(컷 경계 표시·클릭 점프)
   ▲선택중                       각 세그먼트: 길이 비례폭, 실패/미선택 컷은 ⚠표시
선택 컷 미리보기 위: [이 컷만 다시] [게시용 품질로 다듬기]  ← 현재 컷 인라인 액션
자막 [켜기/끄기]  BGM [켜기/끄기·트랙▾]  보이스 [켜기/끄기·보이스▾]  (R4-02 복원)
💬 대화형 편집: "마지막 컷 CTA 2초 더"            [적용]
🔒 라이선스 확인된 사운드만 · 업로드는 본인 권리 확인
```
| 규칙 | 내용 |
|---|---|
| 세그먼트 타임라인 | 컷 경계·길이 비례폭, 클릭 시 해당 컷으로 점프, 현재 컷 하이라이트. **모바일 가로 스크롤(내부)·페이지 오버플로 금지**(R4-01 교훈) |
| 미선택/실패 컷 | 타임라인에 ⚠, 재생 시 placeholder + "이 컷 후보 고르기" 유도 |
| 인라인 액션 | 현재 재생 컷에 "이 컷만 다시"·"게시용 품질로 다듬기" 노출(compare 왕복 없이) |
| 자막/사운드 | 토글 + 라이선스 notice(R4-02). 변경 즉시 미리보기 반영(가능 범위) |

**AC:** ①선택 컷들이 순서대로 연속 재생 ②타임라인 세그먼트 클릭→해당 컷 점프 ③미선택/실패 컷이 타임라인에 명확 표시 ④자막/BGM/보이스 토글 동작·저장 ⑤대화형 명령 제출→`applyEdit`+피드백 ⑥타임라인 모바일 가로 오버플로 0.

### 3.C 최종 렌더 플레이어 (`FinalRenderPlayer`) — 내보내기(완료) 화면
```
┌─ 완성본 ────────────────── 1080p ─┐
│            ▶  0:00 / 0:15          │
└────────────────────────────────────┘
길이: [ 6s ][ 15s ][ 30s ]   ← 버전 탭(선택 버전 재생, R4-06)
[⬇ 다운로드] [🔗 공유 링크] [기본 버전으로]
```
| 규칙 | 내용 |
|---|---|
| 버전 탭 | 6/15/30s를 **탭**으로 전환 재생(3행 스택 대체, R4-06). 각 완료 시 활성 |
| 다운로드/공유 | 실제 파일 URL/공유 링크(R4-05). 진행 중 버전은 탭에 진행률 |
| 기본 버전 | "이 버전을 기본으로" 지정(대시보드 썸네일·공유 기본) |

**AC:** ①완료 버전 탭 재생 ②다운로드→파일/서명URL ③공유→링크 복사 토스트 ④진행 중 버전 탭에 단계·진행률 ⑤모델명 0.
