# 09 · Claude R3 — Mock App QA & Next.js 앱화 UX 보강

변증법: R1(설계·프로토타입) → Codex R1(계약·OpenAPI·schema·routing) → R2(provider 과보장 표현 완화) → **Codex R2(mock backend vertical slice 구현·push)** → **이 문서 = Claude R3**.

**대상:** 라이브 mock-app — https://gmpark-creator.github.io/project-dashboard/ai-video-studio/mock-app/
**방법:** 코드 정독(app.js·mock-api.js·styles.css) + Edge 헤드리스 실측(데스크탑 1366px·모바일 390px, 전체 플로우 walk, 스크린샷, 자동 프로브: 모델명 누출·비용표시·dev잭곤·품질숫자·가로오버플로).
**원칙:** 코드 직접 수정 안 함(제안만 문서화). 모델명 비노출 유지. 백엔드 미구현.

## 0. QA 요약 (Executive)

**✅ 통과(유지할 것)**
- **모델명/엔진명 UI 누출 0건** — 전 6화면 + 생성/재시도/승급/렌더 상태 스캔. `engineUsed`(mock.fast.primary 등) 렌더 안 됨.
- **부분 실패 격리** — 10컷 중 2컷(컷5·컷9) 실패해도 나머지 8컷 검토·진행 정상.
- **이전 Take 보존** — 재시도/승급이 기존 후보를 지우지 않고 새 후보만 추가.
- **실패 안내 존재** — 실패 컷에 "생성 실패. 이 컷만 다시 시도해도 이전 후보와 다른 컷은 보존됩니다." 노출.
- **4K 표현 R2 반영** — "4K는 기본 보장 기능이 아니라 내보내기/업스케일 옵션입니다." ✓
- **비용 인라인** — 대부분의 비용 액션 버튼에 ⚡ 표시.
- **모바일 가로 오버플로 0** — dashboard·new·storyboard·**compare(populated)**·export. (단 **edit 예외** ↓)
- **과장 표현 없음** — "AI가 완벽히 고쳐줌" 류 카피 미발견.

**발견 이슈:** **P0 ×2 · P1 ×13 · P2 ×8** — 직접 QA 13건(R3-01~13) + 독립 3-렌즈 교차검증 추가 11건(R3-14~24). [교차검증 §2 하단]

## 5. 상태별 사용자 문구 (11 상태)

> 배지/라벨은 한국어 체감어, 메시지는 비기술·안심·다음행동. 엔진명 0.

| 상태(내부) | 배지/라벨 | 사용자 메시지 | 버튼 |
|---|---|---|---|
| `queued` | 대기 중 | "차례를 기다리고 있어요. 곧 시작해요." | (취소) |
| `running` | 만드는 중 | "영상을 만들고 있어요… (약 N초)" | (진행률·취소) |
| `done` | 완료 | "완성됐어요. 후보를 비교해 골라보세요." | 후보 비교 / 선택 |
| `failed` | 실패 | "이 컷을 만드는 데 문제가 생겼어요. 다른 컷은 그대로예요." | **이 컷만 다시(primary)** · 다른 방식으로 시도 |
| `fallback suggested` | 다른 방식 권장 | "이 컷은 다른 방식으로 다시 시도하면 잘 될 수 있어요." | 다른 방식으로 다시 |
| `regenerating` | 다시 만드는 중 | "이전 후보는 보존하고 새 후보를 만들고 있어요." | (진행·취소) |
| `upgrading` | 게시용 다듬는 중 | "게시용 고품질로 다시 다듬고 있어요." | (진행·취소) |
| `rendering` | 영상 합치는 중 | "고른 컷을 한 편으로 합치고 있어요… (약 N초)" | (단계·진행률) |
| `render failed` | 내보내기 실패 | "최종 영상으로 합치는 중 문제가 생겼어요. 컷·설정은 그대로예요." | 다시 내보내기 |
| `insufficient credits` | 크레딧 부족 | "크레딧이 부족해요. 지금까지 작업은 저장돼 있어요." | 저비용으로 낮추기 · 크레딧 충전 |
| `expired media URL` | 다시 불러오는 중 | "영상을 불러오지 못했어요. 다시 불러올게요." | 새로고침(자동 URL 갱신) |

> 렌더 단계명(stage) 한국어 매핑: assemble→"컷 합치는 중", audio_mix→"소리 입히는 중", caption_burn→"자막 입히는 중", encode→"마무리 인코딩 중", done→(단계 숨김).
