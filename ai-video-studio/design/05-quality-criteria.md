# 05 · 품질 평가 기준 (Quality Criteria)

디렉터 요청 ⑤ 항목. 6축 각각: **정의 → 좋음/나쁨 신호 → 측정(자동+사람) → 1~5 루브릭 → UX 피드백 루프**.
용도: ① 컷 자동 품질배지(⚠) ② Take 자동추천 점수 ③ 재생성/승급 권유 ④ 내보내기 전 게이트.

> **측정 책임 분담:** 자동 신호 산출(임베딩 유사도·옵티컬플로우·A/V 싱크·VMAF 등)은 **Codex(검증)** 영역. 여기서는 *무엇을·왜·어떻게 UX에 반영*하는지의 **기준과 임계 정책**을 정의한다.

## 점수 모델
- 각 축 **1~5**(1=재생성 필요, 3=수용 가능, 5=우수). 컷 종합점수 = 가중평균.
- **가중치는 Intent별로 다름**(데이터로 분리). 예: 교육=프롬프트 충실도·완성도↑, 쇼츠=모션·페이싱↑, 브랜드=일관성·전환↑.
- 임계: 축 점수 **≤2 → ⚠ 배지 + 재생성 권유**. 종합 **≥4 → "고품질 승급" 추천**.

---

## ① 프롬프트 충실도 (Prompt Fidelity)
| 항목 | 내용 |
|---|---|
| 정의 | 생성 결과가 SAEC 프롬프트(피사체·동작·환경·카메라)를 얼마나 반영하는가 |
| 좋음 | 지정 피사체/동작/구도/카메라 모션이 그대로 나타남 |
| 나쁨 | 동작 누락, 다른 피사체, 카메라 모션 무시, 텍스트/로고 오生성 |
| 자동 신호 | 프롬프트↔프레임 CLIP/비전-언어 정합 점수, 객체 검출 일치, (텍스트요구 시) OCR |
| 사람 | "요청대로 나왔나?" 썸업/다운 |
| 루브릭 | 5 핵심요소 100% · 3 주요요소 일치/부차 누락 · 1 의도 빗나감 |
| UX 루프 | ≤2 → "프롬프트 손보기" 또는 "다시" 권유, SAEC 폼에서 누락 필드 하이라이트 |

## ② 피사체 일관성 (Subject Consistency)
| 항목 | 내용 |
|---|---|
| 정의 | 동일 인물/제품이 컷 전반에서 같은 정체성(얼굴·의상·색·형태)을 유지 |
| 좋음 | 멀티샷에서 얼굴/의상/제품 외형 동일 |
| 나쁨 | 컷마다 얼굴·의상·색 변함(가장 흔한 멀티샷 실패) |
| 자동 신호 | 얼굴/제품 임베딩 코사인 유사도(컷 간), 색 히스토그램 드리프트 |
| 사람 | "같은 사람/제품으로 보이나?" |
| 루브릭 | 5 구분 불가 · 3 경미한 드리프트 · 1 명백히 다른 대상 |
| UX 루프 | 낮으면 🔒 캐릭터 레퍼런스 등록/재주입 권유([UX §6](03-ux-rules.md)). 익스트림 앵글·초저조도 경고 |

## ③ 모션 자연스러움 (Motion Naturalness)
| 항목 | 내용 |
|---|---|
| 정의 | 움직임의 물리적 그럴듯함(무게·관성·유체), 아티팩트 부재 |
| 좋음 | 자연스러운 가속/감속, 물·천·머릿결 사실적, 손가락 정상 |
| 나쁨 | 흔들림·플리커·모핑·프레임 점프, 손가락/객체 변형, 인과 오류 |
| 자동 신호 | 옵티컬 플로우 급변·지터 지수, 시간적 일관성, 손/얼굴 아티팩트 검출 |
| 사람 | "움직임이 어색한가?" |
| 루브릭 | 5 매끄럽고 사실적 · 3 경미 지터 · 1 심한 모핑/플리커 |
| UX 루프 | ≤2 → ⚠"모션 흔들림 의심" + "이 컷만 다시"(P5). 물리모션 컷은 Luma 라우팅 힌트 |

## ④ 장면 전환 품질 (Scene Transition Quality)
| 항목 | 내용 |
|---|---|
| 정의 | 컷↔컷 연결의 매끄러움(컬러·연속성·리듬) |
| 좋음 | 컬러/조명 연속, 모션 매치컷, 점프 없음, 의도된 리듬 |
| 나쁨 | 컬러 점프, 어색한 점프컷, 페이싱 붕괴, 연속성 깨짐 |
| 자동 신호 | 경계 프레임 컬러/노출 델타, 컷 길이 분포 vs 목적 페이싱, 모션 연속성 |
| 사람 | "이어지는 느낌인가?" |
| 루브릭 | 5 매끄러운 흐름 · 3 약간 튐 · 1 끊김/리듬 붕괴 |
| UX 루프 | 통합 LUT 자동 적용, 0.5~1s 크로스디졸브/매치컷 제안, 페이싱 경고 |

## ⑤ 자막 / 음성 / 음악 적합성 (Caption · Voice · Music Suitability)
| 항목 | 내용 |
|---|---|
| 정의 | 자막 싱크·가독, 보이스 명료·립싱크, BGM 톤/볼륨 균형 |
| 좋음 | 자막 타이밍·줄바꿈 정확, 보이스 또렷·대사 싱크, BGM 더킹(보이스 우선) |
| 나쁨 | 자막 어긋남/잘림, 보이스 뭉개짐/립싱크 어긋남, BGM이 음성 가림 |
| 자동 신호 | A/V 싱크 오프셋(ms), 자막-오디오 정렬, 라우드니스(LUFS)·더킹 검사, 립싱크 정합 |
| 사람 | "잘 들리고 잘 읽히나?" |
| 루브릭 | 5 방송급 균형 · 3 경미 어긋남 · 1 싱크/가독 실패 |
| UX 루프 | 자막 자동 재싱크, LUFS 정규화·자동 더킹, 립싱크 필요 시 Veo 3.1 라우팅 |

## ⑥ 최종 영상 완성도 (Final Completeness)
| 항목 | 내용 |
|---|---|
| 정의 | 한 편으로서 목적 달성·기술 무결성(전 컷 채워짐, 길이/비율/해상도 충족, 훅·CTA 존재) |
| 좋음 | 빈 컷 0, 목적 구조(훅~CTA) 충족, 포맷 스펙 일치, 워터마크/자막 정상 |
| 나쁨 | 미완 컷, 길이 미달/초과, 비율 틀림, CTA 누락, 인코딩 결함 |
| 자동 신호 | 컷 채움률, 길이/비율/해상도 검증, 블랙프레임·오디오결손 검사, (선택) VMAF |
| 사람 | "이대로 게시 가능한가?" |
| 루브릭 | 5 게시 준비완료 · 3 소폭 보완 · 1 미완성 |
| UX 루프 | **내보내기 전 게이트**: 미충족 항목 체크리스트 + 자동수정/해당 컷 이동 |

## 자동 품질 게이트 (Codex 검증 파이프라인 요구사항)
| 시점 | 게이트 | 동작 |
|---|---|---|
| Take 생성 직후 | 축 ①②③ 자동 스코어 | 점수 부착 → 비교화면 자동추천·⚠배지 |
| 컷 선택 시 | 일관성/전환 인접 검사 | 드리프트 시 레퍼런스/LUT 제안 |
| 다듬기(화면5) | 축 ⑤ A/V·자막·라우드니스 | 자동 재싱크·더킹·정규화 초안 |
| 내보내기 전 | 축 ⑥ 완성도 체크리스트 | 미충족 차단 + 수정 동선 |

## "체감 언어" 매핑 (사용자에겐 점수 대신 말로)
| 내부 신호 | 사용자 표현 |
|---|---|
| 모션 점수 낮음 | "움직임이 조금 흔들려요 — 다시 생성할까요?" |
| 일관성 낮음 | "인물이 컷마다 달라 보여요 — 같은 얼굴로 고정할까요?" |
| 충실도 낮음 | "요청한 ○○이 잘 안 보여요 — 프롬프트를 손볼까요?" |
| 완성도 OK | "게시 준비됐어요 ✨" |

> 사용자는 **숫자/축 이름을 보지 않는다.** 점수는 추천·정렬·배지·권유 문구를 만드는 *내부 연료*. (UX-2.4·UX-1.x와 일관.)
