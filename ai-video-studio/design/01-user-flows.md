# 01 · 핵심 사용자 플로우 (User Flows)

디렉터 요청 ① 항목. **"아이디어 → 완성 MP4"** 를 7단계로 잇되, 각 단계에서 *비전문가가 막히지 않도록* 기본값·자동화·되돌아가기를 명시한다.

## 1.1 골든 패스 (Happy Path) — 7단계

```
 ┌──────────────┐   ┌──────────────┐   ┌──────────────────┐   ┌──────────────────┐
 │ ① 아이디어    │ → │ ② 목적 선택   │ → │ ③ 장면/샷 자동분해 │ → │ ④ 모델별 결과 비교 │
 │   입력        │   │ (Intent)     │   │  (스토리보드)     │   │  (Take A/B/C)    │
 └──────────────┘   └──────────────┘   └──────────────────┘   └──────────────────┘
                                                                          │
 ┌──────────────┐   ┌──────────────────────┐   ┌──────────────────┐      ▼
 │ ⑦ 최종 MP4    │ ← │ ⑥ 자막/BGM/보이스 추가 │ ← │ ⑤ 마음에 드는 컷  │ ←────┘
 │   출력        │   │   (대화형 편집)        │   │   선택            │
 └──────────────┘   └──────────────────────┘   └──────────────────┘
```

| 단계 | 사용자가 하는 일 | 시스템이 대신 하는 일 (자동) | 핵심 UX 규칙 |
|---|---|---|---|
| **① 아이디어 입력** | 한 줄~한 문단으로 "만들고 싶은 영상" 서술. (선택) 참고 이미지/제품URL/스크립트 첨부 | 입력 의도 파싱, 누락 정보 1~2개만 역질문 | 빈 입력에도 예시 프롬프트 칩 제공. 질문은 최대 2개(P3) |
| **② 목적 선택** | 6개 목적 중 택1 (쇼츠/광고/앱소개/공간/교육/캠페인) — 또는 "추천대로" | 목적별 **기본 비율·길이·샷수·톤·티어** 프리셋 적용([템플릿](04-templates.md)) | 목적이 화면비/길이/엔진 기본값을 결정 → 이후 묻지 않음 |
| **③ 장면/샷 자동분해** | 생성된 스토리보드(장면·샷 리스트)를 훑어보고 필요 시 수정 | LLM이 SAEC로 아이디어→Scene→Shot 분해, 샷별 프롬프트 초안 작성 | "1 장소/시간 변화=1 Scene, 1 주요동작=1 Shot". 편집은 카드 드래그/대화로 |
| **④ 모델별 결과 비교** | 컷마다 후보(Take) 2~3개를 나란히 보고 판단 | 각 Shot을 **빠른 미리보기 티어**로 1차 생성(자동 라우팅), Take 병렬 생성 | 모델명 비노출. "A안/B안" 라벨. 비용은 버튼 위 표시(P6) |
| **⑤ 컷 선택** | 컷마다 마음에 드는 Take를 고름. 불만 컷은 "다시"·"이 부분만" | 선택 시 그 Take를 Shot의 final로 픽스. 미선택 컷은 추천 자동선택 | **실패/불만 컷만** 재생성(P5, 이전 Take 보존). 만족 컷은 "게시용 품질로 다듬기" 1클릭(P2) |
| **⑥ 자막/BGM/보이스 추가** | "자막 켜줘", "신나는 BGM", "내 목소리로 내레이션" 등 대화 또는 토글 | 자막 자동생성·싱크, BGM 추천·자동 더킹, TTS/보이스 적용 | 타임라인 없이 **대화형**(P4). 자동 초안 후 미세조정만 |
| **⑦ 최종 MP4 출력** | 해상도/길이컷(6s·15s·30s) 선택 후 "내보내기" | Render Job: 컷 합치기·오디오 믹스·자막 번인·인코딩·(업스케일) | 진행률·예상시간·크레딧 표시. 완료 시 다운로드 + 파생본 자동생성 |

## 1.2 분기·대안 경로 (Alternate Paths)

| 분기 | 트리거 | 동작 |
|---|---|---|
| **빠른 한 방(Express)** | "그냥 알아서 만들어줘" | ②~⑥ 전부 자동 → ⑦ 직전에 "이대로 OK / 손보기" 만 물음 (InVideo식 완성본 우선) |
| **스크립트 입력** | 사용자가 대본/URL 첨부 | ③에서 대본을 직접 Scene/Shot으로 분해(LTX식). 아이디어 파싱 생략 |
| **이미지→영상** | 참고 이미지 첨부 | 해당 Shot은 image-to-video 요구플래그 ON → 라우팅이 **Luma Ray 2** 우선 |
| **캐릭터 일관 필요** | 동일 인물 반복 등장 | 첫 확정 Take에서 레퍼런스 프레임 자동 추출 → 이후 모든 Shot에 주입([UX규칙 §6](03-ux-rules.md)) |
| **목적 미정** | ②에서 "모르겠음" | 아이디어 기반으로 목적 1순위 추천 + 변경 가능 |

## 1.3 실패·엣지 경로 (Failure & Edge) — 반드시 설계할 것
> 상황별 사용자 메시지·버튼 카피는 [08 §5 실패/폴백 UX](08-claude-r2-ux-corrections.md#5-실패--폴백-상태-ux-상황별-문구버튼)에 확정.

| 상황 | 사용자에게 보이는 것 | 복구 동작 |
|---|---|---|
| **Generation Job 실패**(엔진 오류/타임아웃) | 해당 Take 카드만 "재시도" 상태(전체 멈춤 X) | 자동 1회 재시도 → 실패 시 대안 엔진으로 폴백 제안 |
| **품질 미달 자동탐지** | 컷에 ⚠️ 배지("모션 흔들림 의심") | [품질기준](05-quality-criteria.md) 자동검사 → "이 컷만 다시 생성" 권유 |
| **부분 실패**(10컷 중 2컷 실패) | 실패 2컷만 표시, 나머지는 진행 | **실패 컷만** 재생성 큐에 (P5). 전체 재생성 금지 |
| **크레딧 부족** | 생성 버튼 비활성 + 잔액/필요량 표시 | "저비용 티어로 낮추기" 또는 충전 유도. 작업은 보존 |
| **지역 제한**(Veo 얼굴 생성 EU/UK 등 차단) | 해당 옵션 회색 + 사유 툴팁 | 라우팅이 대체 엔진으로 자동 우회([부록](07-engine-research-appendix.md)) |
| **엔진 점검/다운** | 영향 티어만 "일시 지연" 배너 | 라우팅이 가용 엔진으로 자동 전환, 큐 유지 |
| **세션 이탈/새로고침** | 작업 자동저장됨 표시 | Project 상태 영속 → 어느 단계든 복귀(자동저장은 백엔드 요구사항) |

## 1.4 Project 상태 머신 (프론트가 알아야 하는 상태)

```
draft ──(목적·스토리보드 확정)──▶ storyboarded ──(1차 생성)──▶ generating
  ▲                                                              │
  │(언제든 편집 복귀)                                            ▼
  └──────────────── reviewing ◀──(Take 생성 완료)────────────── (부분완료도 reviewing)
                       │ │
        (컷 선택 완료) │ └──(재생성 요청)──▶ generating (해당 Shot만)
                       ▼
                    edited ──(자막/BGM/보이스 확정)──▶ rendering ──▶ done
                                                          │
                                                          └──(실패)──▶ render_failed → 재시도
```

- **상태는 Project·Scene·Shot·Take 각 레벨**에 존재(중첩). 예: Project=`reviewing`인데 특정 Shot=`generating`일 수 있음 → 화면은 부분 진행을 항상 표시(전체 블로킹 금지).
- 자세한 상태/필드는 [계약 문서 §2 데이터 모델](06-frontend-backend-contract.md#2-데이터-모델-프론트가-기대하는-형태) 참조.

## 1.5 인터랙션 원칙 (이 플로우에 한정)
1. **되돌아가기 무손실**: 어느 단계로 가도 이전 산출물·선택은 보존.
2. **부분 진행 우선**: 1개 컷이 늦어도 나머지는 보여준다(Job별 독립 렌더).
3. **자동 후 미세조정**: 모든 단계는 "AI가 해 놓은 것"을 사용자가 *고치는* 형태. 백지에서 시작 금지.
4. **한 번에 하나의 결정**: 한 화면은 사용자에게 한 종류의 결정만 요구(목적이면 목적, 선택이면 선택).
