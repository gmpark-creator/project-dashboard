# 보세사 1과목 2023년 B형 추가 (2026-06-14, Claude)

박사 직접지시(통관축이나 직접지시 시 Claude 작업 가능). 다운로드 폴더
`[003강]2023년_수출입통관절차_기출해설특강_(1번~25번)(...)`의 두 PDF
(「2023년 보세사 기출문제 (강의용).pdf」 = 문제, 「...정답 (강의용).pdf」 = 정답표)를
2023년 1과목(수출입통관절차) **B형**으로 대시보드에 추가.

## 핵심 발견 — B형 = A형 13칸 회전
- 문제 PDF는 전 과목(1~5과목) 38쪽 풀세트. **1과목 = 1~8쪽(8쪽 상단까지)**.
- B형은 A형과 **동일 시험**(문항·선지·정답 동일)이며 출제 순서만 다름.
- 정확한 매핑: **B(n) = A(n+12) for n=1..13, B(n) = A(n−13) for n=14..25** (13칸 회전).
  - 즉 B1=A13, …, B13=A25, B14=A1, …, B25=A12.
- 검증: 25문항 전부 B형 공식 정답표 == 매핑된 A형 twin 정답 (Q16 복수정답 ④⑤ 포함). 100% 일치.

## B형 공식 정답표(1과목)
`1,4,4,3,2,3,3,4,2,1,3,2,3,1,4,(4·5),2,3,5,1,4,5,2,5,2`  (Q16 복수정답)

## 생성 방법
- 검증된 `bosesa-data-1-2023.js`(A형, 기존 QA 완료본)를 회전 매핑해
  `bosesa-data-1-2023b.js`(`BOSESA_DATA_1_2023B`, `answerForm:"B형"`) 생성.
- 텍스트/선지/정답/해설(answerBasis·choiceAnalysis)은 A형 검증본을 그대로 사용(동일 시험이므로 일관성·정확성 유지).
- 노드 스크립트로 25문항 정답키 전수 대조 + 스키마(choices/choiceAnalysis 길이, answer 범위) 검증 PASS.
