- 대시보드 기준: `claude/previews/tradelogix-nexus/bosesa-data-2-2019.js` ~ `bosesa-data-2-2025.js`
- 범위: 문제 본문과 선지 텍스트만 대조
- 제외: 정답 번호, 정답 근거, 해설, 법령 정합성

## 방법

각 PDF를 200 DPI 이미지로 렌더링한 뒤 Windows 한국어 OCR(`Windows.Media.Ocr`, `ko`)로 원문 초안을 만들었다. 대시보드 JS 데이터는 Node로 정규화해 문제 본문과 1~5번 선지 단위로 비교했다.

상세 후보는 별도 JSON에 남겼다.

- `internal/notes/2026-06-13-bosesa-subject2-pdf-text-audit-targets.json`

JSON의 `records[]`는 다음 필드를 가진다.

- `year`: 연도
- `no`: 문항 번호
- `field`: `stem` 또는 선지 번호 `1`~`5`
- `score`: OCR 원문과 대시보드 문구의 유사도
- `dashboard`: 현재 대시보드 문구
- `pdf_ocr`: PDF OCR 원문 후보

`score < 0.75`는 우선 보정 대상으로 본다. 단, OCR 결과는 원문 이미지와 재확인한 뒤 실제 데이터 보정에 반영해야 한다.

## 전체 판단

2과목 데이터는 일부 오탈자만 있는 상태가 아니라, 2019~2025년 전반에서 문제/선지 전사 불일치가 광범위하게 존재한다. 특히 2019~2024년은 거의 전연도 재전사 수준의 보정이 필요하다. 2025년은 상대적으로 양호하지만 Q1, Q2 등에서도 명확한 선지 전사 오류가 확인된다.

## 후속 작업 지시

2과목 보정은 `answer` 배열을 먼저 건드리지 말고, 위 JSON의 `records`를 기준으로 문제 본문과 선지 텍스트를 PDF 원문에 맞춰 교체한다. 보정 후에는 2과목 7개 파일 전체에 대해 다음을 확인한다.

- 각 연도 25문항 유지
- 각 문항 선지 5개 유지
- 뷰어 렌더에서 Q1~Q25 표시
- 기존 정답값 보존 여부 별도 확인
